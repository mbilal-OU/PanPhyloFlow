# Software references

Users should cite the underlying tools actually used in an analysis.

- **Prokka** — Seemann T. Prokka: rapid prokaryotic genome annotation. *Bioinformatics* (2014). Prokka is maintained mainly for compatibility in PanPhyloFlow v0.1.0; its maintainer recommends Bakta for modern annotation workflows.
- **Panaroo** — Tonkin-Hill G, et al. Producing polished prokaryotic pangenomes with the Panaroo pipeline. *Genome Biology* (2020).
- **Roary** — Page AJ, et al. Roary: rapid large-scale prokaryote pan genome analysis. *Bioinformatics* (2015).
- **IQ-TREE 3** — Wong TKF, et al. IQ-TREE 3: Phylogenomic Inference Software using Complex Evolutionary Models. *Molecular Biology and Evolution* (2026), msag117.
- **Nextflow** — cite the current Nextflow workflow-framework reference recommended by the Nextflow documentation.

PanPhyloFlow citation metadata are provided in `CITATION.cff`. A DOI should be added after the first archived public release.
