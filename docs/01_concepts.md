# 1. The biological question

Before running software, define the comparison.

A species-level collection, a genus-level collection, and a cross-phylum collection are different biological objects. As taxonomic breadth increases, homologous genes become harder to cluster consistently and the set of genes shared by nearly all genomes generally changes.

## Questions to write down first

- What is the taxonomic scope?
- Why were these genomes sampled?
- Are assemblies comparable in completeness and quality?
- Are annotations generated consistently?
- Is the objective gene-content diversity, phylogeny, functional comparison, or all three?

## Core idea

The pipeline produces an **analysis-defined pangenome** for a specified genome collection. It does not discover a single universal pangenome independent of method and sampling.
