# 6. Reading the output without overclaiming

## Frequency classes

The report uses descriptive classes:

- persistent: present in at least 95% of genomes;
- shell: present in 15% to <95%;
- cloud: present in <15%.

Your configured `--core_threshold` is reported separately.

## Accumulation curve

The default curve uses one seeded random ordering of genomes. It is a descriptive visualization, not a formal test of pangenome openness.

A formal open/closed analysis requires an explicit model, resampling strategy, and attention to genome sampling.

## Common analytical traps

- interpreting assembly gaps as true absence;
- mixing annotations generated by different pipelines;
- comparing pangenome sizes across studies with different clustering settings as though they were directly equivalent;
- calling a lineage-specific gene adaptive solely because it is accessory;
- treating the core-gene tree and accessory-gene similarity as the same evolutionary signal.
